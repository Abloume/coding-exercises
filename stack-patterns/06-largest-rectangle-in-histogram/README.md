# 06 柱状图中最大的矩形

> 模式：栈 **C2 单调栈 · 面积类**（见 [STACK-PATTERNS.md](../../STACK-PATTERNS.md)）

## 题目

给定 `n` 个非负整数表示柱状图中每根柱子的高度，求该柱状图中能够勾勒出的矩形的**最大面积**。

**示例**：`[2,1,5,6,2,3]` → `10`（高 5、6 的两根柱子构成宽 2、高 5 的矩形）

## 思路：单调递增栈 + 头尾 0 哨兵

**核心洞察**：以第 `i` 根柱子高度为矩形高的最大面积 =
`height[i] × (右边第一个更矮的下标 − 左边第一个更矮的下标 − 1)`。

遍历到**更矮**的柱子时，栈顶柱子的"右边界"确定了 → 弹出结算。

```go
func LargestRectangleArea(heights []int) int {
	// 头尾补 0 哨兵：头 0 保证栈非空（左边界永远存在），尾 0 保证全部弹出
	h := append([]int{0}, heights...)
	h = append(h, 0)

	stack := make([]int, 0, len(h)) // 单调递增栈，存下标
	maxArea := 0

	for i, height := range h {
		// 当前柱子比栈顶矮 → 栈顶的右边界确定，弹出结算
		for len(stack) > 0 && height < h[stack[len(stack)-1]] {
			top := stack[len(stack)-1]
			stack = stack[:len(stack)-1]
			// 高 = 弹出柱子高度；宽 = i - 新栈顶 - 1（新栈顶即左边第一个更矮）
			area := h[top] * (i - stack[len(stack)-1] - 1)
			if area > maxArea {
				maxArea = area
			}
		}
		stack = append(stack, i)
	}

	return maxArea
}
```

### 为什么弹出后"新栈顶"就是左边界？

单调**递增**栈里，新栈顶是栈中比 `top` 更靠左、且高度**小于等于** `top` 的第一个柱子——
因为栈内高度递增，所有比 `top` 高的柱子都在它之前被弹掉了。所以：
- **左边界** = 新栈顶（左边第一个比 `top` 矮的）
- **右边界** = 当前 `i`（右边第一个比 `top` 矮的）

### 哨兵的作用（关键简化）

| 哨兵 | 位置 | 作用 |
|---|---|---|
| 头 0 | 数组最前 | 栈永不空 → 任何柱子都有左边界，**省掉接雨水里的"栈空 break"分支** |
| 尾 0 | 数组最后 | 遍历结束强制全部弹出结算 → **不漏算任何柱子** |

## 与接雨水（42）的镜像关系（务必对比着记）

| | 42 接雨水 | 84 最大矩形 |
|---|---|---|
| 栈单调性 | **递减**（找凹槽：两边高中间低） | **递增**（找柱子：两边低中间高） |
| 弹出时结算 | 水量，水面 = `min(左,右)` − 底 | 面积，高 = **栈顶自身** |
| 边界处理 | 栈空 break（无左边界不积水） | 头尾 0 哨兵（逻辑统一无分支） |
| 一句话 | 凹槽能装多少水 | 柱子能撑多大矩形 |

**为什么一个递减一个递增**：接雨水要"新元素比栈顶高"才形成凹槽；最大矩形要"新元素比栈顶矮"才找到右边界。单调方向由"结算触发条件"决定。

## 复杂度

- 时间：O(n)（每个下标最多入栈/出栈一次）
- 空间：O(n)（栈）
