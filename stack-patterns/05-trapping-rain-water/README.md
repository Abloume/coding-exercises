# 05 接雨水

> 模式：栈 **C2 单调栈 · 面积类**（见 [STACK-PATTERNS.md](../../STACK-PATTERNS.md)）

## 题目

给定 `n` 个非负整数表示宽度为 `1` 的柱子高度图，计算下雨后能接多少雨水。

**示例**：`[0,1,0,2,1,0,1,3,2,1,2,1]` → `6`

## 思路：单调递减栈（按"层"结算水量）

**为什么是单调递减栈**：只有"高度先降后升"（凹陷）才能积水。栈从底到顶高度递减，遇到比栈顶高的柱子，说明栈顶处出现凹陷 → 弹出结算。

```go
func Trap(height []int) int {
	stack := make([]int, 0, len(height)) // 单调递减栈，存下标
	total := 0

	for i, h := range height {
		for len(stack) > 0 && h > height[stack[len(stack)-1]] {
			top := stack[len(stack)-1]
			stack = stack[:len(stack)-1]

			if len(stack) == 0 {
				break // 没有左边界，无法形成凹槽
			}

			left := stack[len(stack)-1] // 左边界 = 弹出后的新栈顶
			width := i - left - 1
			water := (min(height[left], h) - height[top]) * width
			total += water
		}
		stack = append(stack, i)
	}

	return total
}
```

### 凹槽如何结算（关键理解）

弹出 `top` 时，凹陷的三要素齐了：
- **底部** = `height[top]`（被弹出的柱子）
- **左边界** = 弹出后的新栈顶 `left`（左边最近的、不低于 bottom 的柱子）
- **右边界** = 当前 `i`

水量 = `(min(左高, 右高) - 底高) × (右下标 - 左下标 - 1)`——**两边较低者决定水面**，减去底部是凹槽净深，宽度是两边界之间的空隙。

**为什么"弹出后栈空就 break"**：没有左边界时，水会从左侧流走，不能积水（如 `[2,1]` 的 `1` 无法兜住水）。

### 与 739 / 496 的同与异

| | 739 每日温度 | 496 下一个更大 | 42 接雨水 |
|---|---|---|---|
| 栈单调性 | 递减 | 递减 | 递减 |
| 栈内存 | 下标 | 值 | 下标 |
| 弹出时结算 | 距离 `i-top` | 更大值 `x` | 水量 `(min·宽)` |
| 共性 | **弹出栈顶的那一刻，答案确定** | 同左 | 同左 |

## 复杂度

- 时间：O(n)（每个下标最多入栈/出栈一次）
- 空间：O(n)（栈）

> 补充：本题还有**双指针解法**（O(1) 空间，从两端向中间收缩，谁矮谁动）——思路不同但同为 O(n)，面试时两种都要能讲。
