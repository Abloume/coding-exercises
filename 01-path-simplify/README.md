# 01 路径简化

## 题目

将路径 `../a/../../...././b/c/../d/../` 转化为最终的路径。

## 规则

- `.` 表示当前目录，忽略；
- `..` 表示上一级目录，若已在根目录则停在原地；
- 其余分段（包括 `....` 这类特殊名字）一律视为**普通目录名**；
- 最终输出相对路径形式（不补前导 `/`）。

## 答案

最终路径：`..../b`

> `....` 是四个点的目录名，不是两个 `..` 的连写——这是本题最大的坑。

## 常见示例

| 输入 | 输出 |
|---|---|
| `/home/` | `home` |
| `/a/./b/../../c/` | `c` |
| `/a//b////c/d/././..` | `a/b/c` |
| `/../` | `（根，空）` |
| `.../a` | `.../a` |
| `a/b/..` | `a` |
| `src/utils/../../lib/core/../index.ts` | `lib/index.ts` |

## 推导过程

| 分段 | 动作 | 栈 |
|---|---|---|
| `..` | 已在根，忽略 | `[]` |
| `a` | 进入 | `[a]` |
| `..` | 返回上一级 | `[]` |
| `..` | 已在根，忽略 | `[]` |
| `....` | 普通目录名，进入 | `[....]` |
| `.` | 当前目录，忽略 | `[....]` |
| `b` | 进入 | `[...., b]` |
| `c` | 进入 | `[...., b, c]` |
| `..` | 返回上一级 | `[...., b]` |
| `d` | 进入 | `[...., b, d]` |
| `..` | 返回上一级 | `[...., b]` |

## 思路

用**栈**模拟目录进出：按 `/` 切分路径，逐段处理。

- 空段、`.` → 跳过
- `..` → 栈非空则出栈
- 其他 → 入栈

## 复杂度

- 时间：O(n)
- 空间：O(n)
